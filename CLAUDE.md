# Musique: инструкция для Claude Code

Все правила проекта лежат в [AGENTS.md](AGENTS.md): прочитайте его целиком до первой правки.

@AGENTS.md

Коротко для Claude Code: работать только в ветке `dev`; в `main` вливать только после прямого «да, в main»;
тексты в обоих языках; только плоские цвета и отступы из шкалы `tokens.css`; после правки `docs/` поднять версию
(`node scripts/version.mjs NN`); перед «готово» пройти `node scripts/check.mjs`, `npm test`, серверные и браузерные
тесты и посмотреть экран в браузере (375 и 1280 px, обе темы).
