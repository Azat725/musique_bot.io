# Musique

Telegram-бот с Mini App для прослушивания музыки. Поиск по YouTube Music, воспроизведение с YouTube
(с автоматическим фолбэком на SoundCloud), избранное, плейлисты, история и полноэкранный плеер-винил.

- **Mini App** — `docs/`, статический сайт на GitHub Pages: https://azat725.github.io/musique_bot.io/docs/
- **Сервер** — `server/`: бот (aiogram) + API (FastAPI) в одном процессе, запускается на вашем ПК
  и публикуется наружу через бесплатный SSH-туннель localhost.run.

## Запуск

1. Скопируйте `server/.env.example` в `server/.env` и впишите `BOT_TOKEN`.
2. Дважды кликните `start.bat` (или `powershell -File start.ps1`).

Скрипт сам создаст виртуальное окружение (Python 3.12), поставит зависимости и `ffmpeg`, а сервер
поднимет SSH-туннель localhost.run и пропишет его адрес в кнопку меню бота. Пока окно открыто — бот работает.

- Адрес туннеля меняется при каждом запуске и при переподключении. Сервер сам переподключает туннель
  и обновляет кнопку меню; кнопки в старых сообщениях ведут на старый адрес — откройте приложение
  через меню или отправьте `/start`.
- Бесплатный туннель медленный (~20–30 КБ/с), поэтому поток для мини-аппы перекодируется в AAC 64 kbps
  (`STREAM_BITRATE`), а следующий трек в очереди готовится заранее. В чат бот присылает оригинал.
- Если сеть пропускает Cloudflare (порт 7844), можно запустить `start.ps1 -Tunnel cloudflare` — он быстрее.
- На VPS с доменом туннель не нужен: задайте `PUBLIC_API_URL` и `STREAM_BITRATE=0`.

## YouTube и cookies

YouTube иногда требует «подтвердить, что вы не бот». Тогда трек берётся с SoundCloud (дольше стартует,
подходит не для всех треков). Чтобы YouTube работал стабильно, положите `server/cookies.txt`
(формат Netscape, экспорт из браузера расширением вроде «Get cookies.txt LOCALLY»). Лучше использовать
отдельный аккаунт Google — cookies дают доступ к аккаунту, не публикуйте этот файл (он в `.gitignore`).
